# 채널(공개 프로필) 명세서

- **Date**: 2026-11-24
- **Version**: v1.0.0
- **관련 코드**: `apps/api/src/channel/`, `apps/web/src/pages/ChannelPage.jsx`, `apps/web/src/hooks/useChannel.js`, `apps/web/src/components/home/PlaylistAuthor.jsx`
- **관련 스키마**: [supabase_profile_handles.sql](./supabase_profile_handles.sql) (핸들)

리스너마다 핸들 주소(`/@handle`)로 들어가는 공개 페이지가 있습니다. 앞으로 피드·팔로우 같은 기능을 얹을 기반입니다.

## 1. 주소
- `/@handle` (대소문자 구분 없음). 앱 라우트 `/:channelPath`에서 `@`로 시작하는 경로만 채널로 보고, 나머지 한 단계 경로는 전처럼 홈으로 보냅니다.
- 핸들을 바꾸면 이전 주소는 더 이상 열리지 않습니다 (이전 핸들은 30일 동안 다른 사람이 가져갈 수 없음).

## 2. 보여 주는 것
| 항목 | 비고 |
| :--- | :--- |
| 닉네임, 핸들 | |
| 프로필 이미지 | 직접 올린 이미지만 (Google 사진은 쓰지 않음) |
| 가입 연월 | |
| 공개 플레이리스트 | 익명('익명의 리스너')으로 공유한 것과 곡이 없는 것은 제외 |
| 플레이리스트·곡·받은 좋아요 수 | 좋아요는 `get_playlist_signal_stats`와 같은 기준 (가입 3일 이상 계정만) |

보여 주지 않는 것: 이메일, 출생 연도·성별, 감상 기록, 비공개 플레이리스트.

## 3. 익명·정지
- 설정의 '공유 플레이리스트에 닉네임 표시'를 끄면 채널에 플레이리스트를 하나도 보여 주지 않습니다 (익명 플레이리스트가 채널과 연결되지 않게).
- 익명으로 공유한 플레이리스트에는 서버가 작성자 핸들(`authorHandle`)을 내보내지 않아 채널 링크가 생기지 않습니다.
- 정지된 계정의 채널은 없는 채널(404)로 다룹니다.

## 4. API
- `GET /api/channels/:handle` (로그인 불필요): `{ handle, nickname, avatarUrl, joinedAt, stats: { playlists, tracks, likes }, playlists[] }`
- 서버 캐시 60초, IP당 분당 120회 제한 (핸들 수집 방지)
- 없는 핸들·예약어·정지 계정은 404

## 5. 채널로 가는 길
- 플레이리스트 카드의 작성자(아바타·이름)를 누르면 그 사람의 채널로 이동합니다 (카드 재생·열기와 분리).
- 내 정보의 '내 채널' 버튼, 채널의 '링크 복사'

## 6. 다음 단계
- 플레이리스트 작성자를 `playlists.author` 문자열이 아니라 프로필(닉네임·핸들)에서 읽도록 바꾸기
- 팔로우, 채널 소개 글, 대표 플레이리스트 고정
