# Theme, Category, and Genre Playlists Specification

## 개요 (Overview)
`sofar` 홈 패널에 실시간 백엔드 차트 및 트랙 데이터를 분석·분류하여 테마별, 장르별, 상황별 큐레이션 플레이리스트를 제공하는 기능 명세입니다.

---

## 백엔드 자동 선곡 파이프라인 (`apps/api`)

- **Bugs 공식 실시간 한국 장르 차트 스크래핑 파이프라인 (`scrapeBugsGenreChart`)**:
  - 대한민국 벅스(Bugs)의 세부 장르별 공식 차트 코드(`nb`: 발라드, `ndp`: 댄스, `nrh`: 힙합, `nrs`: R&B/소울, `nkrock`: 록/밴드, `nindie`: 인디, `nfa`: 포크/어쿠스틱, `nost`: OST)를 직접 비동기 스크래핑.
  - 수집 결과는 출처가 제공하는 장르 차트 신호로만 분류하며, 애매한 복합 장르 묶음 없이 단일 장르별 플레이리스트로 명확하게 분리합니다.
- **알고리즘 큐레이션**:
  - 곡 목록을 직접 관리하지 않습니다. 플레이리스트 프로필이 허용 장르, 장르별 최대 곡 수, 아티스트별 최대 곡 수, 길이만 선언합니다.
  - 후보는 장르 적합도, 차트 순위, 인기도로 점수화하고 동일 곡·아티스트 쏠림·장르 쏠림을 제한해 자동 선택합니다.
- **엔드포인트**: `GET /api/chart/categories`

---

## 프론트엔드 UI/UX 구성 (`apps/web`)

1. **위치**: `HomePanel.jsx` 내 `TrendingSection` 직후에 배치
2. **카테고리 탭 필터링**:
   - `전체` (`all`)
   - `공유` (`shared`) - 실제 공개된 사용자 플레이리스트만 표시하며, sofar 시스템 큐레이션은 섞지 않음
   - `장르별` (`genre`) - 발라드, 댄스, 힙합, R&B / 소울, 록 / 밴드, 인디, 포크 / 어쿠스틱, OST
   - `테마/분위기` (`theme`) - sofar 알고리즘 큐레이션의 장르 조합 셀렉션
   - `상황/기분` (`situation`) - sofar 알고리즘 큐레이션의 장르 발견·조합 셀렉션
3. **인터랙션**:
   - 카드를 클릭 시 사이드바 플레이리스트 뷰로 전환되어 전체 곡 목록 확인 가능.
   - 카드 호버 시 나타나는 원클릭 재생 버튼으로 해당 플레이리스트 전체 재생 시작.
   - 더보기 케밥 메뉴를 통해 대기열 추가 및 전체 재생 옵션 제공.

---

## 향후 확장 원칙

무드·시대·에너지처럼 장르 차트만으로 입증할 수 없는 큐레이션은 라이선스가 확인된 메타데이터 또는 오디오 특성 공급원이 추가된 뒤에만 노출합니다. 추가 신호는 곡별로 캐시하고, 선곡 프로필의 점수 항목으로 넣어 자동 생성 구조를 유지합니다.
