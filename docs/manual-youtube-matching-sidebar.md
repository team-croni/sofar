# 관리자 수동 매칭 오른쪽 사이드바 (Manual YouTube Matching Sidebar) 규격

- **최종 수정일**: 2026-08-13
- **버전**: v1.1.0

## 1. 개요
관리자가 잘못 매칭된 유튜브 음원이나 사용자의 일치/불일치 피드백 평가 데이터를 기반으로, 원하는 곡과 유튜브 영상 비디오 ID(11자리)를 빠르고 정확하게 찾아 수동 매칭을 진행할 수 있도록 관리자 전용 오른쪽 사이드 패널을 제공합니다.

## 2. 주요 구성요소 및 UI 구조
- **AdminHeader 토글 버튼**: `AdminHeader` 우측 영역에 컴팩트한 텍스트 없는 `PanelRight` 아이콘 전용 버튼이 위치하며, 툴팁이 지원되고 클릭 시 오른쪽 사이드바를 열고 닫을 수 있습니다.
- **Drag and Drop 트랙 자동 입력**: 오른쪽 사이드바의 곡/유튜브 결과 카드를 드래그하여 수록곡 목록에 끌어다 놓으면 지정한 정밀 위치에 순서대로 트랙이 자동 삽입됩니다.
- **AdminRightSidebar (390px 글래스모피즘 사이드 패널)**:
  - **패널 헤더**: "수동 매칭" 뱃지, "유튜브 음원 매칭" 타이틀 및 닫기(`X`) 버튼
  - **탭 1: 노래 검색**:
    - iTunes Open API (`https://itunes.apple.com/search?term=...`) 연동
    - 곡명, 아티스트명, 앨범명, 600x600 고화질 앨범 커버 art 및 재생시간 표시
    - **[유튜브 매칭 검색]** 버튼: 클릭 시 아티스트+곡명 조합으로 유튜브 검색 탭으로 자동 전환 및 검색 실행
    - **[곡 정보 복사]** 버튼
  - **탭 2: 유튜브 영상 검색**:
    - 키워드 검색 또는 유튜브 URL / 11자리 Video ID 직접 입력 감지
    - 백엔드 키리스 YouTube 검색 API (`/api/chart/search-youtube?q=...`) 연동
    - 고화질 썸네일, 영상 제목, 채널명, 재생길이, `v={videoId}` 뱃지 표시
    - **[Video ID 복사]** 버튼: 11자리 비디오 ID 원클릭 클립보드 복사 및 토스트 팝업 안내
    - **[유튜브에서 보기]** 버튼: 외부 유튜브 링크 새 탭 오픈

## 3. 상태 관리 (AdminContext)
- `isRightSidebarOpen` (boolean): 사이드바 열림/닫힘 상태
- `rightSidebarTab` ('song' | 'youtube'): 현재 활성화된 탭
- `rightSidebarQuery` (string): 유튜브 검색어로 연동되는 질의문
- `searchYoutubeFromSong(artist, title)`: 노래 검색 결과에서 유튜브 매칭 검색으로 이동하는 전역 액션
